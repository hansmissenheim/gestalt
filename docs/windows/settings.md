# Settings

Current system settings applied after a fresh install.

## Display

Resolution, refresh rate, and scaling. Values differ per machine — see notes.

## System

Hostname, timezone, and other system-level preferences.

## Mouse & Input

Pointer speed, acceleration, and additional input settings.

## Sound

Per-device audio output configuration.

## Power & Sleep

Power plan and sleep/wake behavior.

## Remote Desktop

Remote access configuration.

## Registry

Registry tweaks that can't be set through the UI.
